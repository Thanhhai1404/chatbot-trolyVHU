# Scripts Utility

Thư mục này chứa các scripts hỗ trợ phát triển và testing.

## Files

- `create_full_programs_data.py`: Script tạo dữ liệu programs.json
- `create_full_tuition_data.py`: Script tạo dữ liệu tuition.json
- `test_tuition_calculation_v2.py`: Test tự động tính học phí
- `update_actions_tone.py`: Mapping tone changes
- `test_chatbot.py`: Test chatbot functionality
- `test_intents.py`: Test intent recognition

## Sử dụng

```bash
# Test tính học phí
python scripts/test_tuition_calculation_v2.py

# Test chatbot
python scripts/test_chatbot.py
```
